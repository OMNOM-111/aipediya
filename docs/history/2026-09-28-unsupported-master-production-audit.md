## Разбивка и смысл полей

`M → P` = Master → Production; примеры не заменяют полного плана. «Другой PK» означает, что соответствующая содержательная строка уже есть в Production с тем же значением поля. Причина `unsupported`: `catalog/master_sync.py::_unsupported` сравнивает вспомогательные строки по `Key` и не пишет перечисленные поля; общий Source/Service также не обновляется из отдельной карточки.

## Происхождение, предшествующие задачи и следующий шаг

Changelog фиксирует массовый `import from Local` 25.09 (555 Offers, 812 Origins и 224 Tool Platforms по исходному состоянию); последующие строки и `docs/history/2026-09-26-catalog-master-v013.md`, `2026-09-26-catalog-master-v015.md`, `2026-09-27-catalog-master-v015-final.md` связывают изменения с редакционными BATCH, `tools/master_editorial_2026_09_26.py`, `tools/master_v015_import_2026_09_26.py` и `tools/master_v015_final_2026_09_27.py`. Production пакет 325/147, commit `9ddba83` (Git author `Dimon_pro`, 27.09), документированно сверял содержание при **игнорировании технических PK**. Поэтому точный момент первого расхождения каждого числового PK из Changelog не восстанавливается; 954 подтверждены сравнением содержания на текущем снимке. Git author удостоверяет commit, но не личность исполнителя каждого BATCH: она в Changelog не указана. Evaluation stage 2 документирован отдельно.

Ранее была **частичная задача**: v013 (26.09) классифицировал тогдашние 124 предупреждения и отложил 30 публичных; v015 расширил поддержку новых строк; Release #012 (28.09) зафиксировал 1 067 и потребовал отдельный scoped plan. **Отдельной утверждённой задачи/решения на обработку всех 1 067 до этого аудита не найдено.** Текущая карточка `UNSUPPORTED-MASTER-PROD-AUDIT-2026-09-28` создана отдельно, без Release #, переведена в `review`, не `done`.

Итог по **предупреждениям-полям**, без пересечения: вероятно полезные для сайта **13** (11 URL доступа, 2 заголовка источника Tool); явно Master-only/research **93** (46 доказательств доступа, 46 справочных единиц цены, 1 неподтверждённая цена); ошибочные сравнения/скрытый дубль **955** (954 PK-артефакта, 1 скрытая оценка); пока неясные **6** (2 общих заголовка Qwen, 4 свободных Supported Models). Следующий шаг — отдельно проверить 13 кандидатов и 6 неясных по источникам и публичному UI, затем рассмотреть исправление диагностики сопоставлением естественных ключей; никакие данные этим аудитом не менялись.
