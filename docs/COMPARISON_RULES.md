# Comparison and release rules, 2026-09-20

All matching models are loaded and sorted on the Django server before pagination. Unicode NFKC/casefold keys, with Russian ё treated as е, are used consistently for names and the displayed localized task/access sequences. Task labels and unique access kinds are displayed in the same alphabetic sequence used by the key. The permanent public number breaks ties ascending in both directions. Missing values are last, never zero. Header text/arrow sorts; the separate filter icon focuses the corresponding control; both work by keyboard and touch. Real links preserve no-JS sorting.

Price comparison explicitly uses one unit, payment scope, context band and optional exact condition. The initial price-header action selects standard text input per million tokens. Batch, off-peak, peak, free, annual, flex, fast/high-speed and priority are separate scopes. Cache units are separate. Audio/image-token offers are excluded from the text basis. Base/short excludes explicitly long prompts; known source threshold uncertainty remains visible. The smallest qualifying offer is selected (amount then stable offer ID), and its supplier and full conditions are displayed. Media/subscriptions additionally select an exact condition rather than mixing resolution/tiers. The all-conditions/all-contexts options are explicit opt-ins and labelled as such. Existing prices and source conditions remain unchanged in SQLite; complete English translations are presentation-only.

Score comparison uses one Benchmark (version/protocol), configuration and snapshot. ECI is the official Epoch model-group composite, not a per-effort score, percentage, safety audit, or media quality score. It includes mixed provenance inputs and preserves the published 90% bootstrap interval. An unknown ECI is never substituted by another test. The most recent measurement then ID is used if the selected configuration contains repeated runs; no best-score search across modes. Source's own `Best score (across scorers)` column is labelled in provenance and is distinct from choosing a model's best effort. `evaluated_only=1` explicitly removes missing scores; normal sorting retains them.

`0009_evaluation_observations` removes the coarse model+benchmark uniqueness and adds immutable observation identity, source model/run/file digest, mode, snapshot and provenance kind. New imports use only the allowlisted 14 Epoch own-run CSVs and official ECI model scores. No external component CSV is imported. Exact reviewed alias registry required; fuzzy matching never publishes. Old evaluations are enriched with `update_fields` that excludes score, preserving their raw original precision. DeepSeek original V4 Pro run id WUk3f44JhxtAJaSxi6gFZR is explicitly moved from the August 0813 card to its historical April card, with audit entries on both cards.

Intentional regression expectation updates: “Independent evaluation” became “Evaluator & score”; missing scores now stay last instead of being silently filtered, with explicit evaluated_only coverage; Text now means the displayed Text task (the state-preservation fixture uses its actual Coding task); API price unit became Price unit because media and subscriptions are now selectable. No checks were removed. New tests verify all rows across pages, directions, languages, unknowns, mode separation, dry run and repeat imports.
