# AIpedia — визуальная спецификация утверждённого эталона

Источник: `artifacts/reference-plan-design.png` (1672×941, копия
`Desktop\План!--дизайн_AIpedia.png`). Все значения сняты пиксельными
промерами оригинала, а не уменьшенного превью.

**Все размеры приблизительные (±2 px), цвета — ±2 единицы канала**, если не
указано иное. Метод: вертикальные и горизонтальные сканы строк пикселей
(`artifacts/imgtool.ps1`, режимы `rowscan` / `colscan` / `pixels`), границы
определялись по скачку яркости относительно фона.

Эталон нарисован с вымышленными данными (Gemini 1.5 Pro, 1 247 записей,
официальные логотипы, «Рейтинг Alpedia 75 %»). Воспроизводится **оформление**,
а не эти значения.

## 9. Осознанные отличия от эталона

1. **Знаки разработчиков** — у каждой опубликованной карточки знак
   организации из `static/marks/` (SVG или PNG). Одна организация — один
   знак для всех её моделей. Если знака нет, остаётся нейтральный инициал.
2. **Кнопка закрытия панели** в эталоне не нарисована; в Local она нужна
   для работы (клавиатура, мобильный оверлей). Оставлена приглушённой
   слева в верхнем ряду панели.
3. **Переключатель Local / Production** — функция только Local, в эталоне
   его нет. Размещён компактно перед RU/EN.
4. **Иконки фильтров в шапке таблицы** — в эталоне нарисованы только
   стрелки сортировки. Фильтры сохранены, но показываются при наведении и
   фокусе, чтобы не засорять шапку.
5. **Данные** (числа, цены, даты, названия) — настоящие из Local; значения
   из макета не копируются.
