# Решения AIpedia

Канонический журнал решений. Идея в обсуждении **не** является требованием.
Статусы: `предложено`, `подтверждено владельцем`, `отклонено`, `заменено новым решением`.
Подробности сравнения — `docs/COMPARISON_RULES.md`. Выпуски — `docs/history/`.
Правила работы исполнителей — `AGENTS.md`, сюда не копировать.

## D-2026-09-18-two-page-catalog

- Статус: заменено новым решением
- Решение: публичный сайт — справочник из каталога (таблица) и карточки модели. RU/EN, без маркетингового блока и без третьего публичного шаблона.
- Заменено: `D-2026-09-21-catalog-panel`. Старые адреса `/models/<slug>` сохраняются.
- Источник: исходное поручение и `README.md`

## D-2026-09-18-missing-not-zero

- Статус: подтверждено владельцем
- Решение: неизвестные значения оставлять пустыми, не подставлять ноль. Неизвестные в сортировке — в конце.
- Источник: `README.md`, `docs/COMPARISON_RULES.md`

## D-2026-09-20-chronology-numbers

- Статус: подтверждено владельцем
- Дата: 2026-09-20
- Решение: публичные номера следуют подтверждённым датам выпуска точной версии (сначала старые). URL, pk и slug — идентичность, не номер.
- Заменяет: требование постоянных номеров, не зависящих от даты.
- Источник: `docs/COMPARISON_RULES.md`, `docs/history/2026-09-20-chronology-release.md`

## D-2026-09-20-undated-last

- Статус: подтверждено владельцем (применён рекомендованный вариант; отдельного ответа на уточняющий вопрос не было)
- Решение: карточки без доказанной даты выпуска остаются доступны, без номера, в конце любого хронологического направления. Дату репозитория и дату проверки не выдавать за дату выпуска.
- Отклонено: выдуманная датировка, чтобы пронумеровать все 255.
- Источник: `docs/history/2026-09-20-chronology-release.md`

## D-2026-09-20-local-production-split

- Статус: подтверждено владельцем
- Решение: одна кодовая база, два окружения. Local — loopback и отдельная SQLite. Production — https://aipediya.com/. Кнопка Production только открывает публичный сайт.
- Отклонено: считать commit, push или кнопку Production публикацией.
- Источник: поручение владельца, `AGENTS.md`, `docs/RELEASE.md`

## D-2026-09-20-no-sqlite-overwrite

- Статус: подтверждено владельцем
- Решение: локальную SQLite никогда не копировать поверх `/srv/aipedia/data/aipedia.sqlite3`. Code-only выпуск: `tools/build_code_release.py` и `tools/deploy_code_release.py`.
- Отклонено: использовать `tools/deploy_release.py` / `tools/deploy_chronology.py` для обычного обновления кода.
- Источник: `docs/RELEASE.md`

## D-2026-09-20-keep-site-and-history

## D-2026-09-21-transfer-pack

- Статус: подтверждено владельцем
- Решение: живой статус — `docs/EXECUTION_STATE.md`. Пакет нового чата собирается в `AI_CONTEXT/` из документов проекта. Исполнитель обязан обновлять статус и собирать пакет; скрипт пишет только факты.

## D-2026-09-21-model-tool-catalog-split

- Статус: подтверждено владельцем
- Дата: 2026-09-21
- Решение: публичный каталог имеет только две самостоятельные вкладки —
  «Модели» и «Инструменты». Вкладки «Все» нет. Модели читаются из
  `ModelVersion(entry_type=model)`, инструменты — из отдельной таблицы `Tool`;
  для сохранения прежних цен, доступов и истории `Tool.legacy_version` защищённо
  ссылается на исходную строку `ModelVersion`.
- Нумерация: у моделей и инструментов две независимые последовательности по
  подтверждённой дате выпуска. Неизвестные даты остаются без номера и в конце;
  фильтры номер не пересчитывают.
- Представление: Models и Tools имеют разные query/view model, конфигурации
  колонок, фильтры, строки и содержимое правой панели. Tool panel не показывает
  контекст, model benchmark и AIpedia Model Rating.
- Источник: прямое поручение владельца о разделении каталога.

## D-2026-09-21-model-origin-country

- Статус: подтверждено владельцем
- Дата: 2026-09-21
- Решение: происхождение модели хранится как нормализованная связь
  `ModelOriginCountry` с ISO 3166-1 alpha-2, источником и датой проверки.
  Связь допускает несколько стран. Неизвестная страна остаётся без связи и без
  фиктивного флага. UI использует локальный SVG-спрайт `static/flags.svg`.
- Источник: прямое поручение владельца; официальные профили организаций,
  сохранённые как `Source`.

## D-2026-09-21-tool-platform-evidence

- Статус: подтверждено владельцем
- Дата: 2026-09-21
- Решение: платформы инструментов нормализованы через `Platform` / `ToolPlatform`.
  Общее подтверждение Desktop/Mobile не расширяется до Windows/macOS/Linux или
  iOS/Android без отдельного источника. Локальный клиент не считается локальным
  inference; это отдельное поле `local_execution` (`Да` / `Нет` / `Гибрид` / пусто).
- Источник: прямое поручение владельца не подменять неизвестные значения.
