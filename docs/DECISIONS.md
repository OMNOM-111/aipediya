# Решения AIpedia

Канонический журнал решений. Идея в обсуждении **не** является требованием.
Статусы: `предложено`, `подтверждено владельцем`, `отклонено`, `заменено новым решением`.
Подробности сравнения — `docs/COMPARISON_RULES.md`. Выпуски — `docs/history/`.
Правила работы исполнителей — `AGENTS.md`, сюда не копировать.

## D-2026-09-23-controlled-term-localization

- Статус: подтверждено владельцем
- Дата: 2026-09-23
- Решение: контролируемые человекочитаемые метки каталога (метки разработчика/
  провайдера вроде «Самостоятельно», единицы биллинга, метки ценовых условий,
  метки конфигурации/протокола оценок), исторически записанные по-русски,
  локализуются детерминированно на все 22 локали в коде
  (`catalog/controlled_terms.py`, `catalog/evaluation_labels.py`) — без Azure и
  без изменения данных. Бренды, ID моделей, имена тарифов (`Pro`, `Max`,
  `Standard`, `ChatGPT Pro`, `Pay-as-you-go`), API/SDK/IDE, разрешения и URL не
  переводятся; английский — только аварийный fallback, не штатный результат для
  поддерживаемой локали. Украинский переводится (кириллический алфавит — не
  русская утечка).
- Отклонено: оставлять русские метки или английский fallback как штатный
  результат для 22 языков; использовать Azure для этих меток.
- Источник: поручение владельца 2026-09-23 (после находки «Модель» на корейской
  странице); аудит всех 22 локалей — 0 русских утечек, 0 английского fallback на
  поддерживаемых локалях.

## D-2026-09-23-panel-ui-and-translation-transfer

- Статус: подтверждено владельцем
- Дата: 2026-09-23
- Решение: (1) правая панель каталога закрывается по клику вне её, по Escape и
  по крестику; клики внутри панели, по шапке (язык/поиск/тема), по ссылке строки
  и по фильтру колонки её не закрывают. (2) Слои z-index зафиксированы шкалой
  (`--z-panel` 30 < `--z-header` 40 < `--z-popover` 50); на узких экранах панель
  начинается ниже шапки (`--aip-header-h`), поэтому языковое меню и его список
  всегда доступны и рисуются над панелью. (3) Перенос переводов между базами
  выполняется идемпотентными командами `export_translations`/`import_translations`
  по ключу slug+поле+язык+sha256(английского источника); импорт не вызывает
  провайдер и применяет перевод только при совпадении английского источника.
- Отклонено: закрывать панель добавлением затемняющего фона (меняет desktop-вид);
  копировать Local SQLite поверх серверной базы для переноса переводов.
- Источник: явный финальный мандат владельца 2026-09-23; `docs/RELEASE.md`.

## D-2026-09-21-model-tool-catalog-split

- Статус: подтверждено владельцем
- Дата: 2026-09-21
- Решение: публичный каталог имеет только две самостоятельные вкладки —
  «Модели» и «Инструменты». Вкладки «Все» нет. Модели читаются из
  `ModelVersion(entry_type=model)`, инструменты — из отдельной таблицы `Tool`;
  для сохранения прежних цен, доступов и истории `Tool.legacy_version` защищённо
  ссылается на исходную строку `ModelVersion`.
- Нумерация: у моделей и инструментов две независимые последовательности по
  подтверждённой дате выпуска. Неизвестные даты остаются без номера и в конце;
  фильтры номер не пересчитывают.
- Представление: Models и Tools имеют разные query/view model, конфигурации
  колонок, фильтры, строки и содержимое правой панели. Tool panel не показывает
  контекст, model benchmark и AIpedia Model Rating.
- Источник: прямое поручение владельца о разделении каталога.

## D-2026-09-22-i18n-22-languages

- Статус: подтверждено владельцем
- Дата: 2026-09-22
- Решение: интерфейс и таксономия каталога локализованы на 22 языка. English —
  канонический язык, `x-default` и итоговый fallback. Локаль в существующем
  query-параметре `?lang=` (URL не меняются). Приоритет определения языка:
  URL → cookie `aipedia_lang` → `Accept-Language` → слабый хинт `CF-IPCountry`
  → English. Ручной выбор сохраняется в cookie и не переопределяется гео.
  Статические переводы UI и категорий хранятся в коде
  (`catalog/ui_translations.py`, резолвер `catalog/context.t`/`category_label`),
  а не только в SQLite. Динамический контент каталога использует English
  fallback при отсутствии перевода. `ar` и `fa` работают в RTL через логические
  CSS-свойства. Фактические поля (названия, компании, URL, цены, числа, даты,
  API identifiers) не переводятся.
- Отклонено: 22 независимые копии каталога; переход на path-based `i18n_patterns`
  с потерей старых URL; перевод фактических данных; дублирование канонических
  данных ради каждого языка.
- Источник: прямое поручение владельца полностью реализовать мультиязычность.

## D-2026-09-22-dynamic-translation-pipeline

- Статус: подтверждено владельцем
- Дата: 2026-09-22
- Решение: подготовлен provider-agnostic pipeline автоматического перевода
  будущих динамических данных каталога. English — источник; перевод привязан к
  sha-256 hash исходного английского текста (`catalog.ContentTranslation`),
  состояния `current` / `outdated` / `missing` / `reviewed`. Изменение source
  автоматически (сигнал `pre_save`) делает перевод устаревшим и возвращает
  English fallback до повторного перевода. Перевод выполняется один раз при
  добавлении/изменении данных (команда `translate_catalog`, backfill,
  импорт-хук), не при просмотре. Provider абстрагирован; первый — Microsoft
  Azure Translator (ключ только из env `AIPEDIA_AZURE_TRANSLATOR_KEY`), для
  Local/тестов — offline mock. Ошибка провайдера не ломает сохранение модели и
  сайт. Реальный внешний API в тестах не вызывается.
- Отклонено: перевод через API на каждый просмотр; хранение ключа в коде/Git;
  замена статических 22-язычных переводов UI runtime-переводом.
- Ограничение: Production не публикуется; существующие данные не меняются.
- Источник: прямое поручение владельца добавить независимый этап pipeline.

## D-2026-09-23-dynamic-translation-finalization

- Статус: подтверждено владельцем
- Дата: 2026-09-23
- Решение: локализация доведена до фактически законченного состояния — каждый из
  22 языков отдаёт реально локализованный каталог, а не переведённые кнопки
  вокруг английской карточки. Выполнен реальный Azure backfill (F0, eastus2):
  901 объект, 360 запросов, 1 680 285 биллинг-символов (< 2M бесплатного лимита),
  42 260 `ContentTranslation` (все `current`), dedup через translation memory.
  Страны локализованы детерминированным код-слоем `catalog/countries.py`
  (ISO2 × 22 языка). Прозаические поля моделей/инструментов переведены; бренды,
  model IDs, API/URL, цены, числа, `ecosystem` (бренд-названия) не переводятся.
  `privacy.html` локализована на 22 языка (`catalog/static_pages.py` + overlay).
- Штатный авто-перевод: `AIPEDIA_AUTO_TRANSLATE` — реальная включаемая функция
  (не отключённый эксперимент): `post_save` хук переводит новый/изменённый
  объект после commit; массовые импорты используют `suppress_auto_translation()`
  и один пакетный `translate_catalog`. Включено в `deploy/aipedia.env.example`
  (Production) и Local `.env.local`; в коде по умолчанию off (тесты/миграции).
- Ревизии: удалены 765 технических translation-ревизий, созданных старым
  процессом до guard (точная контент-сигнатура, id 4355–5119, с резервной копией
  БД и доказательством сохранности реальной истории: baseline 4354 восстановлен,
  ни одна модель не потеряла историю). Далее guard исключает машинные записи
  перевода из журнала ревизий.
- Защита технических токенов (`catalog/token_guard.py`): машиночитаемые токены
  (`1M`/`128K`/`7B`/`405B`, версии/ID `gpt-5-pro`/`GPT-5.2`, `API`/`OCR`, URL)
  оборачиваются в `translate="no"` и провайдер шлёт `textType=html`, поэтому
  Azure не превращает их в слова/единицы (реальный дефект `1M → ۱ متр`). Уже
  сохранённые искажения класса «число+единица» (232 пары) отремонтированы
  точечно `repair_token_distortions` (17 запросов, 23 396 символов, 0 ревизий);
  транслитерации имён в индийских/CJK письменностях оставлены (смена письма, не
  семантика; slug/ID/заголовки — латиница; полный ремонт вышел бы за F0).
- `methodology.html` **не удалять**: сейчас orphaned/404, публичную локализованную
  Methodology page отдельно сделает следующая задача Global Search & Discovery.
- Заметки покрытия оценок `evaluation_gap` (AIpediya-авторская проза) не
  переведены: после классификации/dedup нужно **412 820** billable-символов, в
  остатке F0 — **304 215**, дефицит **108 605**. Платные расходы и template-хак
  запрещены. Очередь на следующий период F0 quota:
  `AIpediya-authored eval-gap remaining: 412,820 billable chars; current shortfall: 108,605`.
  Эта часть **НЕ считается завершённой**; всё остальное локализовано.
- Хранилище переводов keyed by locale code и не привязано к URL-схеме: данные и
  translation pipeline переживут смену URL без миграции переводов. Отдельный
  этап Global Search & Discovery позднее изменит routing, reverse, `canonical`,
